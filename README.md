# License Lens

纯前端开源依赖许可证审核台账。面向发布前的许可证合规审核场景，提供可追溯的完整工作流：

- **组合许可证逐条款评估**：支持 SPDX 表达式（`AND` / `OR` / `WITH` / 括号嵌套），每个候选条款分别给出「通过 / 复核 / 冲突」结论及判定依据，再按组合逻辑（OR 取最优路径、AND 取最严格项、例外条款放宽）得出综合结论。
- **分发模型切换**：一键切换「开源分发 / 闭源云服务」，全部依赖的自动评估结论随模型即时变化（如 GPL 在云服务模式下降级、AGPL 保持冲突）。
- **人工结论覆盖**：人工结论记录处理人、说明与时间，覆盖对应依赖的自动判断；支持撤销恢复自动评估，历史决策完整保留。
- **持久化**：依赖清单、人工结论、决策记录、分发模型均存储于 localStorage，关掉页面再打开仍然保留。
- **可追溯报告**：导出的 Markdown 报告包含每项结论的判定依据、每条依赖的决策历史、人工决策存档与完整决策记录。

## 运行

```bash
npm install
npm run dev      # 开发调试
npm run build    # 产出静态文件（dist/），任意静态服务器即可托管
```

依赖清单格式为每行一条：`名称@版本 许可证表达式`，例如：

```
rc@1.2.8 (BSD-2-Clause OR MIT OR Apache-2.0)
font-awesome@6.5.2 (CC-BY-4.0 AND OFL-1.1 AND MIT)
legacy-gpl@2.4.0 GPL-3.0-only
```
