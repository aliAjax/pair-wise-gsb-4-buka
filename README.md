# License Lens · 发布许可证审核台账

发布前的依赖许可证可追溯审核流程（React + Vite）。

## 功能

- **组合许可证按候选条款分别判分**：支持 `A OR B`（任选其一，取最优路径）与 `A AND B`（需同时满足，取最差判定），每个候选条款单独给出「通过 / 复核 / 冲突」及对应依据。
- **分发模式联动**：切换「开源分发 / 闭源云服务」后，条款依据与自动结论按政策库重新计算（如 GPL 在开源分发下冲突、闭源云服务下转复核；AGPL/SSPL 两种模式均冲突；LGPL 仅在分发时需复核）。
- **人工裁定留痕**：记录处理人、说明与时间，覆盖自动判断；切换页面或重开浏览器后从 `localStorage` 恢复；也可一键恢复自动判断（同样写入决策记录）。在另一种分发模式下作出的裁定会提示复核。
- **报告导出**：导出 Markdown 审核报告，包含每项依赖各候选条款的依据、自动/人工/最终结论，以及按时间排序的完整决策记录。

## 开发

```bash
npm run dev      # 本地开发
npm run build    # 类型检查 + 构建
npm run preview  # 预览构建产物
```
